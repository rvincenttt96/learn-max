# گزارش معماری غزال

گزارش خواندنی HTML به‌علاوه دو گزارش متنی و دو دیاگرام تعاملی از وضعیت فعلی سرویس‌ها، فلوها، و مسیر ذخیرهٔ داده.

| فایل | محتوا |
|---|---|
| [report.html](report.html) | گزارش کامل HTML: رول‌کال، Study Plan، شماره پدر/مادر، پیامک، الوکام، کتاب و Acc |
| [report-services.md](report-services.md) | همه سرویس‌ها و فلوهای انتهابه‌انتها |
| [report-database.md](report-database.md) | سه MySQL، خواندن و نوشتن، کش و سیستم‌های بیرونی |
| [ghazal-services.architecture.html](ghazal-services.architecture.html) | نقشه سرویس‌ها (Archify) |
| [ghazal-data.dataflow.html](ghazal-data.dataflow.html) | مسیر داده (Archify) |

دیاگرام‌ها را در مرورگر باز کنید. عنوان‌ها و کارت‌ها فارسی‌اند. نوار ابزار خود Viewer (تم، جستجو، خروجی تصویر) به‌خاطر محدودیت Archify انگلیسی می‌ماند؛ `meta.locale` فقط `en` یا `zh-CN` را می‌پذیرد.

منبع دیاگرام: [Archify](https://github.com/tt-a1i/archify) با پروفایل `showcase` (۹ چک، صفر خطا).
