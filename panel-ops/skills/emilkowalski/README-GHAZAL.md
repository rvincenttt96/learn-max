# معیار طراحی غزال

این پوشه **منبع حقیقت طراحی** پنل آموزشی و حسابداری غزال است.

Upstream (اجباری، از اینجا آمده): https://github.com/emilkowalski/skills

نصب رسمی همان ریپو:

```bash
npx skills@latest add emilkowalski/skills
```

کپی محلی همین‌جاست تا ایجنت بدون شبکه هم همان مهارت‌ها را بخواند. موازی با این درخت، سیستم طراحی دیگری نساز.

## قبل از هر کار UI بخوان

| کار | فایل |
| --- | --- |
| هر طراحی / دکمه / مودال / رنگ / کارت | `skills/emil-design-eng/SKILL.md` |
| هر انیمیشن | `skills/animate/SKILL.md` و در صورت نیاز `skills/animate/RECIPES.md` |
| شیت، فشار دکمه، فاصله، شیشه | `skills/apple-design/SKILL.md` |
| موبایل، تپ، `100vh`، زوم اینپوت | `skills/mobile-native/SKILL.md` |
| اسم بلند، لیست خالی، داده بد | `skills/break-ui/SKILL.md` |
| نقد موشن بعد از نوشتن | `skills/review-animations/SKILL.md` |

قانون Cursor (همیشه روشن): `.cursor/rules/design.mdc`  
مهارت پروژه: `.cursor/skills/ghazal-ui/SKILL.md`

سلام «I'm ready…» اول مهارت‌های Emil را در میانهٔ تسک غزال نگو. مهارت‌ها مشخصات‌اند، نه شخصیت چت.
