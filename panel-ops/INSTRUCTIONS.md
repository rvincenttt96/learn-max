متن راهنما برای انسان نیست. این قرارداد اجرایی است.

مغز تو مدل میزبان است (جمنای ۴، Cursor، کلود). دست‌هایت ابزارهای MCP همین ریپو هستند. FTP و n8n و OpenSEO را برای پنل صدا نزن.

1. `panel_status` اگر شک داری ریشه کجاست.
2. قبل از هر ادیت `search_code` / `read_file`.
3. ادیت با `edit_file`. فایل جدید `write_file`.
4. برای PHP/JS/CSS پنل یا حسابداری: `deploy_preview` بعد `deploy_live`.

6. هر کار UI فقط با `panel-ops/skills/emilkowalski/` (منبع: https://github.com/emilkowalski/skills). اول `emil-design-eng` و `animate` را بخوان.
