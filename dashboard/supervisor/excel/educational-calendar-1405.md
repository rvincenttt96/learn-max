# تقویم آموزشی ۱۴۰۵

مرجع تاریخ ترم‌های آموزشگاه غزال برای سال تحصیلی ۱۴۰۵. اسم‌ها انگلیسی‌اند. اگر خواستید یکی را دوباره وارد کنید، ردیف همان ترم را از جدول یا از فایل اکسل نمونه بردارید.

## ستون‌های اکسل

| ستون | معنی | نمونه |
|---|---|---|
| `year` | سال تحصیلی شمسی | `1405` |
| `term` | نام انگلیسی ترم | `Fall 1` |
| `start` | تاریخ شروع | `1405-06-30` یا `2026-09-21` |
| `end` | تاریخ پایان | `1405-07-28` یا `2026-10-20` |

تاریخ شمسی با `-` یا `/` قبول می‌شود. زوج و فرد روی برگه دو روز دارند؛ در تقویم بازه از زودترین شروع تا دیرترین پایان است.

در صفحه Terms: **وارد کردن تقویم آموزشی (Excel)**. نمونه: `educational-calendar-template.xlsx`.

روی برگه کاغذی ۱۴۰۵ ردیف **بهار ۲** تاریخ خوانا نداشت؛ در نمونه اکسل نیست.

## برنامه ۱۴۰۵

ثبت‌نام = ستونی که روی برگه «از …» آمده. شروع/پایان هر کدام دو روز زوج و فرد دارند.

|---|---|---|---|---|
| Spring 1 | — | — | 1405-02-09 / 1405-02-10 | 1405-03-07 / 1405-03-09 |
| Spring 3 | 1405-02-30 / 1405-02-31 | 1405-03-02 | 1405-03-10 / 1405-03-11 | 1405-04-10 / 1405-04-11 |
| Summer 1 | 1405-04-01 / 1405-04-02 | 1405-04-06 | 1405-04-15 / 1405-04-16 | 1405-05-14 / 1405-05-15 |
| Summer 2 | 1405-05-14 / 1405-05-15 | 1405-05-17 | 1405-05-24 / 1405-05-25 | 1405-06-23 / 1405-06-24 |
| Fall 1 | 1405-06-21 / 1405-06-22 | 1405-06-23 | 1405-06-30 / 1405-06-31 | 1405-07-27 / 1405-07-28 |

برای اکسل تقویم فقط `year` / `term` / `start` / `end` کافی است؛ `start` = اول بازه، `end` = آخر بازه.

## نمونه ردیف اکسل

```
year,term,start,end
1405,Spring 1,1405-02-09,1405-03-09
1405,Summer 2,1405-05-24,1405-06-24
1405,Fall 1,1405-06-30,1405-07-28
```

اگر ترم هم‌نام در همان سال باز باشد، فقط تاریخ‌ها به‌روز می‌شوند. اگر نباشد، ساخته می‌شود.
